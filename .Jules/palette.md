## 2024-03-XX - Initial Assessment
**Learning:** This is a portfolio website using `MagneticButton` wrappers around actual interactive elements (`<a>`, `<button>`). The `MagneticButton` itself is just a `div` wrapper that provides mouse tracking effects. The interactive elements inside need proper accessibility attributes.
**Action:** Add aria-labels and focus-visible rings to interactive elements wrapped by `MagneticButton`.
