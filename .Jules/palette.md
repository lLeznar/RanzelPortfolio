## 2025-06-15 - Inconsistent Accessibility Patterns across UI Sections
**Learning:** Found an accessibility issue where identical interactive patterns (icon-only social links) had `aria-label`s in one section (`ContactSection`) but lacked them in another (`HeroSection`). This reveals a pattern of piecemeal accessibility implementations within the codebase, rather than reusable accessible component patterns. Furthermore, keyboard focus indicators (`focus-visible`) were missing from these interactive elements in the Hero section, creating inconsistent keyboard navigation experiences.
**Action:** Implemented `aria-label` attributes and explicit `focus-visible` styling on the interactive links in the Hero section. For future development, abstract such common UI patterns (like icon-only social links) into a reusable component that enforces accessibility props by default, ensuring consistency across all sections.
